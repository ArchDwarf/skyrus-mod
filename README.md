# SkyRus — русификатор Hypixel SkyBlock

Клиентский мод для **Fabric, Minecraft 26.2**. Переводит на русский всё, что присылает сервер:

| Что | Как |
|---|---|
| Чат, системные сообщения, сообщения игроков | словарь + автоперевод (сообщение придерживается до 1,5 с, пока не придёт перевод, порядок сохраняется) |
| Action bar (❤ Здоровье / ❈ Защита / ✎ Мана) | словарь + автоперевод |
| Названия и описания предметов | словарь + автоперевод |
| Заголовки меню (Bazaar, Auction House, SkyBlock Menu…) | словарь + автоперевод |
| Боковое табло, Tab-список, заголовки /title, полоса босса, надписи над мобами и NPC | словарь + автоперевод |

Обычный интерфейс Minecraft переводится самой игрой: поставьте в настройках язык «Русский».

## Все предметы SkyBlock переведены заранее

В мод встроен файл `assets/skyrus/items_ru.json` с переводом названий и описаний **всех предметов SkyBlock**
(источник — открытый репозиторий [NotEnoughUpdates-REPO](https://github.com/NotEnoughUpdates/NotEnoughUpdates-REPO)).
Описания переводятся целыми абзацами, а числа подставляются из игры, поэтому перевод подходит при любых значениях
характеристик, а цвет чисел сохраняется. Если у предмета есть приставка перековки или звёзды
(«Withered Hyperion ✪✪✪✪✪»), название всё равно узнаётся.

Файл обновляет GitHub Actions (`Перевод предметов SkyBlock`): каждый понедельник он подтягивает новые предметы,
переводит только новое и пересобирает мод. Запустить вручную: вкладка **Actions** → «Перевод предметов SkyBlock» → **Run workflow**.

## Как работает перевод

1. **Словарь** (`assets/skyrus/dictionary.json`, ~2600 записей): характеристики, редкости (с правильным родом: «ЛЕГЕНДАРНЫЙ МЕЧ», «ЛЕГЕНДАРНЫЕ БОТИНКИ»), локации, меню, навыки, мобы, зачарования, материалы, сезоны, время. Мгновенно и без интернета.
2. **Автоперевод** — всё, что осталось на английском, переводится онлайн и сохраняется в `config/skyrus/mt_cache.json`. Каждая строка переводится один раз, дальше берётся из кэша.
   - `google` — по умолчанию, без ключа;
   - `deepl` — лучшее качество, нужен бесплатный ключ с deepl.com (`/skyrus key <ключ>`);
   - `libretranslate` — свой сервер (адрес и ключ в конфиге);
   - `none` — только словарь, без интернета.
3. Ники игроков и слова вроде SkyBlock, Hypixel, MVP+ защищаются и не переводятся. Цвета и форматирование сохраняются.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) для Minecraft 26.2 и положите в `mods` [Fabric API](https://modrinth.com/mod/fabric-api).
2. Положите `skyrus-1.0.0.jar` в папку `mods`.
3. Зайдите на `mc.hypixel.net`.

## Сборка .jar

**Без установки чего-либо (GitHub):** создайте репозиторий, загрузите туда эту папку — вкладка **Actions** сама соберёт мод, готовый .jar будет в артефакте `skyrus-mod`.

**Локально:** нужен JDK 25.
```
gradlew build        (Windows)
./gradlew build      (Linux/macOS)
```
Готовый файл: `build/libs/skyrus-1.0.0.jar`.

Если сборка ругается на версии — возьмите актуальные `loader_version`, `loom_version` и `fabric_api_version` на https://fabricmc.net/develop/ и впишите в `gradle.properties`.

## Команды

| Команда | Что делает |
|---|---|
| `/skyrus` | статус и список команд |
| `/skyrus toggle` | включить/выключить перевод |
| `/skyrus auto` | включить/выключить автоперевод (останется только словарь) |
| `/skyrus provider google\|deepl\|libretranslate\|none` | выбрать переводчик |
| `/skyrus key <ключ>` | ключ DeepL (сразу переключает на DeepL) |
| `/skyrus part <chat\|players\|actionbar\|tooltips\|menus\|titles\|sidebar\|tab\|bossbar\|names>` | включить/выключить перевод отдельной части |
| `/skyrus everywhere` | работать не только на Hypixel |
| `/skyrus reload` | перечитать словари |
| `/skyrus clearcache` | очистить кэш автоперевода |

## Свой словарь

`config/skyrus/dictionary.json` — записи оттуда главнее встроенных. После правки — `/skyrus reload`.

```json
{
  "exact":    { "Click to view!": "Жми, чтобы посмотреть!" },
  "terms":    { "Hyperion": "Гиперион", "Magic Find": "Магическая находка" },
  "patterns": [ { "regex": "\\b(\\d+)s\\b", "replace": "$1 сек." } ],
  "keep":     [ "Dante" ]
}
```

- `exact` — строка целиком;
- `terms` — слово или фраза внутри строки (без учёта регистра; регистр перевода подстраивается: CAPS → КАПС);
- `patterns` — регулярные выражения Java;
- `keep` — никогда не переводить.

Кэш автоперевода (`mt_cache.json`) — обычный JSON «английский → русский». Плохой перевод можно поправить прямо в нём или перенести строку в свой словарь.

## Важно знать

- **Другие моды для SkyBlock** (Skyblocker, Firmament и т.п.) часто узнают меню, сообщения и мобов по английскому тексту. Если какая-то их функция перестала работать — отключите нужную часть, например `/skyrus part menus`, `/skyrus part names` или `/skyrus part chat`.
- Мод меняет только то, что видите вы; на сервер ничего не отправляется. Тем не менее правила Hypixel о модах решает Hypixel — используйте на своё усмотрение.
- При автопереводе тексты чата и предметов отправляются выбранному сервису перевода (Google/DeepL/LibreTranslate). Если это нежелательно — `/skyrus provider none`.
- Бесплатный Google ограничивает частоту запросов; мод делает не больше 4 запросов в секунду (`maxRequestsPerSecond` в `config/skyrus/config.json`) и при блокировке делает паузу 30 с. Чем дольше играете, тем больше строк в кэше и тем реже нужен интернет.
- Мод написан под Minecraft 26.2 (Mojang-названия классов). Если какой-то миксин не найдёт свой метод в другой версии игры, игра не упадёт — просто эта часть не будет переводиться.

## Структура

```
src/main/java/ru/skyrus/
  SkyRusClient.java        — события Fabric, команды
  SkyRus.java              — перевод Component с сохранением стилей
  ChatQueue.java           — очередь чата, пока идёт автоперевод
  ScreenTitles.java        — исходные заголовки меню
  core/Dictionary.java     — словарь: exact / patterns / terms / keep
  core/StringTranslator.java — перевод строки, §-коды, защита ников
  core/MachineTranslator.java — Google / DeepL / LibreTranslate + кэш
  core/SkyRusConfig.java   — настройки
  mixin/                   — табло, Tab, /title, боссбар, имена сущностей, заголовки экранов
src/main/resources/assets/skyrus/dictionary.json — встроенный словарь
```
